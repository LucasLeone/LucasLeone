# Hi there! 👋

I'm Lucas Leone, a product-minded full-stack developer from Argentina. I work daily with Elixir/Phoenix and React, and I build and run my own SaaS products on Django and AWS.

💼 Currently working at:
- [**InformeMedico**](https://informemedico.com.ar/): Medical imaging platform (PACS, DICOM viewer, study delivery) built with **Elixir & Phoenix** and a **React + TypeScript + Vite** frontend. I work on the DICOM viewer (Dental, 3D and PET-CT fusion modes on Cornerstone3D), an HL7 integration server, and imaging services.
- [**BataEDU**](https://bataedu.com/): Education platform for learning programming — I build the student-facing app with **React, TypeScript, TanStack and Vite**, plus gamification features backed by **Phoenix & Oban**.

🚀 Founder of [Turnero Online](https://turnero-online.me), an appointment scheduling SaaS with 1K+ monthly visitors, built with **Django REST Framework**, **Next.js**, **Celery** and **AWS** (S3, Lambda, IAM).

🏋️  Founder of [MyCentroGym](https://mycentrogym.vercel.app/), a gym management SaaS handling memberships, check-ins, statistics and daily operations.

⚙️  My main stack:
- **Elixir & Phoenix** for concurrent, fault-tolerant systems
- **React, TypeScript, Next.js & TanStack** for modern frontends
- **Django REST Framework** for building robust APIs
- **PostgreSQL** for reliable data management
- **Celery & Oban** for asynchronous task processing
- **Docker** for containerization and reproducible environments
- **AWS** (S3, Lambda, IAM) for storage, backups and automation

🎯 I enjoy owning features end-to-end — from database to production infrastructure — and automating the boring parts.

🎓 Studying Information Systems Engineering at the National Technological University (UTN).
